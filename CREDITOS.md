# Créditos

Este repositório junta a inteligência que usamos para editar vídeo. Uma parte é nossa (os documentos, as skills em
[`skills/`](skills/), o motor de motion e as ferramentas). A outra parte são skills e ferramentas abertas de
terceiros que usamos todos os dias: **elas não são redistribuídas aqui**. Apontamos para o repositório original,
com autor e licença, e a instalação baixa de lá. Todo o mérito delas é de quem as fez.
